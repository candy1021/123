# 数据统计 / 运营看板（浅色）

## 描述

面向**日常查看**的数据页面（管理后台内的统计页、运营看板、报表页），基调是"信息密度高、层级清晰、可筛选钻取"。区别于展厅大屏，本技能使用浅色主题。

配色、字体、间距遵循 `beds-design-system`。

## 使用场景

- 新建数据概览页、运营统计页、报表页
- 制作 KPI 指标卡、趋势图、占比图、排行榜
- 为已有统计页补充筛选、图表、下钻

## 指令

### 一、页面结构

```
页面标题 + 时间范围筛选（今日/近7天/近30天/自定义）
KPI 指标卡区（一行 2–4 个）
图表区（趋势 / 占比 / 排行，2–3 列栅格）
明细表格（可选，钻取用）
```

- 栅格：24 栅格，gutter 16px；KPI 卡一行 4 个（窄屏 2 个）；图表卡默认占 12/24，核心趋势图可占 24/24
- 卡片间距 16px，卡片内边距 24px（紧凑 16px）

### 二、KPI 统计卡规格

| 元素 | 规格 |
|------|------|
| 容器 | 白底，`--beds-shadow-sm`，4px 圆角，padding 20px |
| 标题 | 14px，`#4E5969`，在上 |
| 数值 | 28px / 600，`#1F2329`，`tabular-nums` |
| 环比/同比 | 12px，增长绿 `#00B42A` 涨箭头、下降红 `#F53F3F` 跌箭头 |
| 辅助 | 下方可放迷你走势（sparkline）或单位说明 |
| 图标 | 右上角可放浅色底圆形图标，背景用主色 50 号 `#EFF6FF` |

> 语义色按业务定义：不要固定"绿=好"，退款率上升应为红。指标卡颜色需与业务含义一致。

### 三、图表选型对照

| 数据意图 | 推荐图表 |
|----------|----------|
| 随时间变化趋势 | 折线图 / 面积图 |
| 类别对比 | 柱状图（横向柱用于名称较长时） |
| 占比构成 | 饼图（≤5 项）/ 环形图 / 堆叠柱（多组占比） |
| 排名 | 横向条形图 + 数值标签 |
| 单指标达成率 | 仪表盘 / 进度条 / 环形进度 |
| 多指标同屏 | 小倍数图（sparkline 阵列） |

### 四、图表样式规范

- 配色严格使用图表色板 C1–C9，按顺序取用：`#2563EB` `#14C9C9` `#00B42A` `#F7BA1E` `#F53F3F` `#722ED1` `#F77234` `#60A5FA` `#86909C`
- 坐标轴文字 12px `#86909C`；网格线 `#F0F0F0`，只保留水平网格线
- 图表统一包裹在卡片中：卡片头（标题 14px/500 + 右侧图例/切换/下载，高 40px，底部 1px 分割线），图表区 padding 16px 0
- tooltip：深色底 `rgba(0,0,0,0.75)` + 白字，圆角 4px，padding 8px 12px
- 去掉冗余装饰：不加重阴影、不加 3D、不加背景渐变

### 五、数据与状态处理

- 数字格式化：千分位；大数用"万/亿"；百分比保留 1 位小数；单位（元/次/%）紧随数值
- 空数据：图表区显示"暂无数据"占位，不留白
- 加载中：图表区用骨架屏，避免整页跳动
- 异常：显示"数据加载失败 + 重试"
- 刷新：提供手动刷新入口，并显示"更新时间"；自动轮询间隔 ≥30s，刷新时不要闪烁重绘

## 交付前自检

- [ ] KPI 数值 `tabular-nums`、层级（28/600）正确
- [ ] 图表选型与数据意图匹配
- [ ] 图表色板按 C1–C9 顺序，语义色符合业务
- [ ] 每张图表有标题与容器，坐标轴样式统一
- [ ] 空态 / 加载态 / 失败态齐全，有更新时间
- [ ] 响应式：窄屏卡片自动降为 2 列或 1 列

## 示例

**输入**：做一个销售数据概览页，顶部 4 个 KPI（销售额、订单量、客单价、退货率），中间一张 12 个月的销售趋势折线，右侧一个渠道占比环形图，底部一个商品销售额排行榜。

**输出**：KPI 四卡按规格渲染（退货率上升显示红色）；趋势图占 24/24 或左 16/24；环形图右 8/24；排行榜用横向条形；全部套图表卡容器，配色按 C1–C9，补齐加载/空态，右上角加时间范围切换。
