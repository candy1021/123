# 数据大屏（暗色 / 全屏）

## 描述

面向**展厅、指挥中心、会议汇报**的全屏数据可视化。基调是"暗色科技感、层次分明、数据可读优先"。与浅色管理后台是两套视觉，但共用同一图表色板。

## 使用场景

- 制作 1920×1080 全屏大屏、驾驶舱
- 汇报 / 展厅 / 监控场景的数据可视化
- 需要暗色科技风面板与发光数字效果

## 指令

### 一、画布与适配

- 基准分辨率 **1920×1080**（16:9），固定比例
- 适配方式：整体 `transform: scale()` 等比缩放并居中，**不做响应式重排**（大屏场景重排会破坏构图）
- 四周安全边距 24px，面板之间间距 16px
- 背景色 `#0D1117`；可叠加极淡网格或径向渐变装饰（克制）

### 二、页面结构

```
顶部标题区（64–80px）：居中大标题 + 两侧时间/天气/状态
主体栅格区：3–6–3 / 4–4–4 / 2–8–2 等布局
   左列面板（宽 3 或 4）
   中列面板（宽 6 或 8，通常放地图/核心指标）
   右列面板（宽 3 或 4）
```

- 使用 CSS Grid 12 列；面板高度节奏统一：小面板 220px、中面板 320px、大面板 440px
- 全部面板统一圆角 6px

### 三、面板样式（核心）

| 元素 | 规格 |
|------|------|
| 背景 | `#161B22`，或用 `linear-gradient(135deg, rgba(37,99,235,0.08), rgba(37,99,235,0.02))` |
| 边框 | 1px `rgba(37,99,235,0.25)` 或 `#30363D` |
| 标题栏 | 高 40px，padding 16px；标题 16px/500 浅色 `#F0F6FC`；左侧 4px 蓝色装饰竖线 |
| 内容区 | padding 16px 20px |
| 核心数字 | 32–48px / 600，推荐 `#3B82F6`，可加 `text-shadow: 0 0 12px rgba(59,130,246,0.5)` |
| 辅助文字 | 14px `#8B949E`；标签 12px `#6E7681` |

### 四、暗色文字与图表

- 主文字 `#F0F6FC`，辅助 `#8B949E`，占位 `#6E7681`
- 图表色板保持 C1–C9 不变（`#2563EB` `#14C9C9` `#00B42A` `#F7BA1E` `#F53F3F` `#722ED1` `#F77234` `#60A5FA` `#86909C`），在暗底上区分度良好
- 发光效果：`box-shadow: 0 0 8px {对应色}40`
- 网格线 `#21262D`；坐标轴文字 12px `#8B949E`
- 地图 / 3D 效果需与整体色系一致（蓝青为主）
- **文字与背景对比度 ≥4.5:1**，不要用深灰字压在深底上

### 五、动效（克制是底线）

- 数字可用 countUp 滚动（0.6s 内）
- 边框扫光 / 呼吸光**整屏最多 2–3 处**，只给核心指标
- 图表入场动画 ≤0.6s
- 实时刷新**不加动画**
- 禁止：闪烁、旋转、持续抖动、满屏粒子

## 交付前自检

- [ ] 基准 1920×1080 + `transform: scale` 自适应
- [ ] 背景 `#0D1117`，面板 `#161B22` + `rgba(37,99,235,0.25)` 边框
- [ ] 每个面板都有标题（16px + 左侧蓝色竖线）
- [ ] 数字 `tabular-nums`、字号 ≥20px；核心数字有描边或发光
- [ ] 配色仅用色板 C1–C9，未引入体系外颜色
- [ ] 发光/扫光 ≤3 处，无干扰读数动画
- [ ] 全屏无滚动条，无内容溢出

## 示例

**输入**：做一个"园区能耗监控大屏"，1920×1080，左上角总能耗 KPI，中间园区地图，右侧能耗排行，底部 24 小时能耗趋势。

**输出**：`scale` 自适应的暗色大屏；标题居中带蓝色渐变发光；3–6–3 栅格；四个面板均带蓝色竖线标题栏；KPI 数字 48px 发光；地图与图表使用 C1 主蓝 + C2 青；底部趋势折线带面积渐变；整屏仅 KPI 与标题处两处发光效果。
