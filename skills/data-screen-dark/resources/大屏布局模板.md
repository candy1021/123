# 数据大屏常用布局模板

> 基准分辨率 1920×1080（16:9），四周安全边距 24px，面板间距 16px

---

## 一、自适应缩放（必须）

大屏**不做响应式重排**，而是整体等比缩放并居中：

```js
function fitScreen(el, baseW = 1920, baseH = 1080) {
  const scale = Math.min(window.innerWidth / baseW, window.innerHeight / baseH);
  el.style.transform = `scale(${scale})`;
  el.style.transformOrigin = 'left top';
  el.style.width  = baseW + 'px';
  el.style.height = baseH + 'px';
  // 居中偏移
  el.style.left = (window.innerWidth  - baseW * scale) / 2 + 'px';
  el.style.top  = (window.innerHeight - baseH * scale) / 2 + 'px';
}
window.addEventListener('resize', () => fitScreen(document.querySelector('.screen')));
```

```css
.screen {
  position: fixed;
  background: #0D1117;
  overflow: hidden;
}
```

## 二、常用布局比例（CSS Grid 12 列）

### 布局 1：3–6–3（最常用，核心居中）

```
┌──────────────────────────────────────────────┐
│               顶部标题区 64–80px               │
├──────────┬────────────────────┬──────────────┤
│  左 3    │      中 6          │    右 3      │
│  KPI 卡  │   地图 / 核心指标   │  排行 / 饼图  │
│  趋势图  │                    │  列表        │
└──────────┴────────────────────┴──────────────┘
```

```css
.screen-body {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 16px;
  padding: 0 24px 24px;
}
.col-3 { grid-column: span 3; display: grid; gap: 16px; }
.col-6 { grid-column: span 6; display: grid; gap: 16px; }
```

### 布局 2：4–4–4（三等分，适合并列对比）

```
├──────────┬──────────┬──────────┤
│   左 4   │   中 4   │   右 4   │
└──────────┴──────────┴──────────┘
```

### 布局 3：2–8–2（窄边栏 + 大主视图，适合地图 / 3D）

```
├────┬──────────────────────┬────┤
│ 2  │         8            │ 2  │
└────┴──────────────────────┴────┘
```

### 布局 4：上 2–中 8–下 2（纵向分布，适合流程 / 时间轴）

```
┌──────────────────────────────┐
│           上 2               │
├──────────────────────────────┤
│           中 8               │
├──────────────────────────────┤
│           下 2               │
└──────────────────────────────┘
```

## 三、面板高度节奏（保持统一）

| 类型 | 高度 | 用途 |
|------|------|------|
| 小面板 | 220px | KPI 卡、单指标、小型饼图 |
| 中面板 | 320px | 折线图、柱状图、排行榜 |
| 大面板 | 440px | 地图、核心趋势、多序列图 |

> 同一列内面板高度相加应等于可视区高度（1080 − 标题区 − 边距），避免出现内容溢出或大面积留白。

## 六、使用提示

1. 先定布局比例，再往面板里填内容，避免边做边改结构
2. 面板高度按 220 / 320 / 440 的节奏分配，**同一行对齐**
3. 图表统一用色板 C1–C9，暗底上不要引入体系外颜色
4. 发光效果克制：整屏不超过 2–3 处
5. 交付前在 1920×1080 与 2560×1440 下各看一次缩放是否正常
