# B端表格 / 表单页生成

## 描述

B 后台系统 80% 的页面是"列表 + 筛选 + 表格 + 分页"与"表单 + 校验 + 弹窗"。本技能把这套结构固化为标准模板，任何表格表单页都按此结构与规格生成，保证一致、可复用。

配色、字体、间距等一律遵循 `beds-design-system` 技能（主色 `#2563EB`，行高 48px，正文 14px）。

## 使用场景

- 创建/修改列表页、管理页、台账页
- 创建/修改新增、编辑、详情表单页或弹窗表单
- 增加筛选查询、批量操作、导入导出、行内操作

## 指令

### 一、列表页标准结构（自上而下，顺序固定）

```
页面标题 + 右侧主操作按钮区            ← Page Header，高约 56px
筛选栏（搜索条件）                     ← 白底/浅灰底，padding 16px，圆角 4px，底部 margin 16px
工具栏（新增 / 批量操作 / 导出 / 列设置）← 与表格同容器，底部 margin 12px
数据表格                               ← 白底卡片，圆角 4px
分页器                                 ← 右对齐，与表格间距 16px
```

### 二、表格规格（核心）

- **容器**：白底 `#FFFFFF`，1px `#F0F0F0` 边框，4px 圆角
- **表头**：背景 `#FAFAFA`（灰，**不用蓝色**），文字 14px / 500 / `#1F2329`，高 48px，底部 1px `#F0F0F0`；可排序列 hover 显示排序图标，激活变 `#2563EB`
- **表体**：默认行高 48px（数据密集可用 40px，**不得低于 40px**）；文字 14px / 400
- **行交互**：hover 背景 `#EFF6FF`（过渡 0.2s）；选中背景 `#DBEAFE`，可在左侧加 3px 蓝色指示条
- **单元格**：内边距 垂直 12px / 水平 16px（紧凑 8px / 12px）；文字左对齐，**数字右对齐**，状态居中，操作列右对齐
- **超长文本**：单行省略号 + tooltip，不换行，约 200px 起截断
- **操作列**：优先文字按钮，间距 ≥16px；危险操作红色 `#F53F3F`；超过 3 个操作收进"更多"下拉
- **数值**：启用 `tabular-nums`，金额/数量统一小数位

### 三、列表页必备状态（缺一不可）

| 状态 | 表现 |
|------|------|
| 加载中 | 表格区域 Skeleton 或局部遮罩 |
| 空数据 | 居中占位插图 + "暂无数据" + 可选新建按钮，最小高 200px |
| 筛选无结果 | 文案提示"没有符合条件的数据，试试调整筛选条件" + 重置按钮 |
| 加载失败 | 错误提示 + 重试按钮 |
| 分页 | 右对齐；页码高 32px，当前页蓝底白字；每页条数选择器在左 |

### 四、表单规格

- **布局**：默认水平布局（Label 宽 100px 右对齐，与控件间距 12px）；弹窗/窄栏用垂直布局；搜索栏用行内布局（间距 16px）
- **控件**：
  - 输入框高 40px，左右 padding 12px，圆角 4px，边框 1px `#D9D9D9`
  - focus：边框 `#2563EB` + 焦点环 `0 0 0 2px rgba(37,99,235,0.2)`
  - error：边框 `#F53F3F`，下方 12px 红色错误文字（带图标）
  - disabled：背景 `#F5F5F5`，文字 `#C9CDD4`
- **必填**：Label 前红色 `*` `#F53F3F`，与文字间距 4px
- **分组**：字段多时用分割线或 16px/500 小标题分组，组间距 24px
- **栅格**：24 栅格，普通字段占 12/24（半行），长字段占 24/24；表单项垂直间距 20px（搜索栏 16px）
- **操作栏**：主按钮（提交/保存）置于最右或最醒目处；取消按钮紧邻其左，间距 8px；提交中按钮进入 loading 且禁止重复提交

### 五、表单校验与交互

1. 提交前前端全量校验，错误定位并滚动到**第一个**出错字段
2. 错误信息具体（"请输入手机号"而非"输入有误"），12px、`#F53F3F`
3. 危险/不可逆操作（删除、批量删除）**二次确认**
4. 表单未保存离开时给出提示
5. 提交成功后 Message 提示（3s 自动关闭）+ 关闭弹窗 + 刷新列表

### 六、弹窗表单

- 宽度：表单 520px，详情 720px；圆角 8px；遮罩 `rgba(0,0,0,0.45)`
- 标题栏 16px/500，底部 1px 分割线；内容区 padding 24px
- 底部操作栏右对齐（主按钮最右），顶部 1px 分割线
- 内容超出时最大高度为视口 80%，内容区滚动，标题与操作栏固定

## 交付前自检

- [ ] 页面结构完整（标题 / 筛选 / 工具栏 / 表格 / 分页）
- [ ] 行高 ≥40px，数字右对齐且等宽
- [ ] 空态、加载态、失败态均已实现
- [ ] 表单 Label 宽度统一、必填有红 `*`、有错误提示
- [ ] 危险操作有二次确认
- [ ] 操作按钮主次分明，一行不超过 3 个主按钮

## 示例

**输入**：做一个"用户管理"列表页，支持按姓名/手机号/状态筛选，表格显示头像、姓名、手机号、角色、状态、创建时间、操作（编辑/禁用/删除），带新增按钮和分页。

**输出**：按上述结构生成页面；筛选栏含 3 个条件 + 查询/重置按钮；表格列按"文字左对齐、时间统一格式、状态用 Tag、操作列文字按钮"处理；补齐空态/加载态；新增与编辑复用同一个弹窗表单（520px，必填校验）；删除有二次确认。
